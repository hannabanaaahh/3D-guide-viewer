Guide Viewer

A read-only 3D viewer for step-by-step assembly guides made with Guide Builder. It is one HTML file that you can host anywhere and embed in any page.

Open full screen Open your own .guide file Download the example .guide

Embed a guide on your site

Copy guide-viewer.html and your .guide file to your web host, then add:

<iframe src="guide-viewer.html?src=my-guide.guide"
        style="width:100%;height:640px;border:0"
        allow="fullscreen" title="Assembly guide"></iframe>

Or use Export HTML in Guide Builder to get one file with the guide already inside it.

What readers can do

  • Step through the guide with the buttons, the arrow keys or the step list
  • Turn, zoom and pan the model, and reset to each step's view
  • Read each step's instructions, tips, parts list, hardware and photos
  • Hover over or tap a part to see its name

The options, the postMessage API and the file format are described in the README.
